# CyberApply AI

AI-powered cybersecurity job discovery assistant.

## Goal

Find junior and graduate cybersecurity jobs, rank them against multiple CV profiles, and assist the user with applications.

## Features

- Job collection from online sources
- Cybersecurity role classification
- CV matching
- Application tracking
- Human approval before applying

## CV Profiles

- Blue Team / SOC
- Red Team / Penetration Testing
- Network Security

## Tech Stack

Backend:
- Python
- FastAPI
- SQLAlchemy
- SQLite/PostgreSQL

AI:
- OpenAI API
- NLP matching

Automation:
- Playwright

Frontend:
- React (planned)
